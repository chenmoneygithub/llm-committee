## 2. 每题一份路由；不同条件独立生成

路由使用逻辑成员A/B/C，先规划、后生成。每题固定一份模板，跨三套阵容和三种tone复用；不同题独立随机规划，不根据输出修改路线。记录实际模型与逻辑成员的映射。

1. 从六个不同的sender→receiver组合中随机选两个。receiver回复sender已有的初始答案，各记为对应路径的第1个正式turn。
2. 将两条路径各规划到5个正式回复；下一位从当前发言者以外的两名成员中均匀随机选。
3. 做4次扩展：随机选择一个深度小于5、目前只有一个子回复的节点，给另一位可用receiver增加子回复，并将新支线延伸到深度5。
4. 最终正好六条末端路径，每条五个正式回复，每节点最多两个不同receiver的子回复。共享前缀只生成一次，分叉后的上下文和成员状态隔离。

这套具体二叉/单支规则每场有15–24个唯一正式回复，不再使用旧的26节点宽松上界作为期望；离线路由模拟均值约19.34。六条路径不是六次独立实验。路由相同也不代表跨阵容/tone的文本可复用。

## 3. 一次抽样，供 B/C/D 共同使用

每题×阵容，把三种tone的唯一回复节点合为候选池，总共抽8个目标事件：

- T=1至5，每个位置均匀抽1个节点。
- 余下3个名额，按位置权重 `1:1:1:1:1.5` 选T，再在该T未选中的节点内均匀抽取。位置可重复，节点不可重复。
- 共60×3×8=1,440个目标事件。不给每个tone单独配额，也不为B/C/D分别抽样。D只是主清单中的适用开放成员子集。
- 抽样依赖预规划结构，不依赖自报标签、judge分歧或变化大小。
- 为C/D补齐该成员真实的前次参与与初始参照。参照不必是另一个抽中的目标事件，也不自动增加B评审；同一准确上下文的读数复用。
- 抽中节点若是该成员在某条末端路径上的最后一次参与，再做初始→最终比较。末次参与可能早于T=5；不保证每条分支、每个成员的终点都被测到。
- 每个当前读数都保留相对初始的选项/概率比较；只有逐次及符合条件的首末文本比较送judge，不默认增加“初始→每个中间T”的文本评审。

候选位置T有N_T个节点、权重为w_T时，完整候选池下每节点入样概率为 `π_T=(1+3w_T/5.5)/N_T`。保存该概率以校正抽样，不把位置均衡样本冒称为所有turn等概率样本。缺测不靠另挑符合预期的节点补齐。

## 4. 每层测什么

| 层 | 对象与主要输出 |
|---|---|
| A | 正式回复对实际peer消息的四档自报agreement；比较tone/阵容，并保留指令消融 |
| B | 单judge读原题、peer消息和回复，给四档文本agreement；与同条回复的A标签对应 |
| C | 同成员、同分支的原题选项与完整自身观点：逐次变化，以及抽中终点的首末变化 |
| D | 在相同事件上补充开放模型的原题选项概率和对完整自身观点的认同概率 |
| E | 同一Terra chairman的debate与no-debate最终答案，由单judge双顺序盲选 |

### A/B：对peer的态度不是对原题的立场

A/B四档为完全赞同、部分赞同、部分反对、完全反对。B按实质主张与理由判定，不按礼貌程度判定；未表态、无法判断分别保留，不塞进四档。Judge不见自报标签、tone指令、模型身份。要求给简短文本证据。

A正式统计覆盖全部回复。**A消融的执行建议，尚未单独定过数量：**每题每阵容预选一个逻辑节点，在friendly和hostile的相应实际上下文中，各重新生成一次保留指令回复和一次移除指令回复；不拿原正式回复充当保留组。按60题计，共360个配对上下文、720次新回复；另需720次文本评审（旧预算仍基于80题）。没有额外C/D消融。中性条件不额外做“移除不存在的tone指令”。这只改变当前回复的指令，不抹去历史中已经产生的文字。该规模明确列为集中确认的建议，不是追认为用户已定。

### C：选项与完整观点分开记录

在隔离的上下文副本上，初始及所需参与后节点生成 `choice + position`。先给原题原生选项对应的标签，再给完整自身观点；不拆成单句claim与rationale。保留自己的正式初始回答、该分支正式历史及该条件原有的系统/tone指令，使用固定措辞的测量请求，不顺手移除tone（那是A消融）。初始读数在加tone/交流前保存，可跨tone复用。旁路测量不回流到讨论、后续测量或chairman。

**已确认不在C请求中新增thinking：**初始、前次参与、当前及终点读数均使用同一直接回答模式，输出选项和完整观点；这不关闭或重跑正式debate的reasoning，也不意味着模型没有内部计算。C测的是既定讨论上下文下、标准化直接提问得到的立场报告，而不是额外再生成一轮推理后的回答。

逐次参照是自己的前次实际参与，不是上一位发言者或上一次碰巧被抽中的节点。选项是否改变由程序比较；原题选项可能无序，不能对任意编号取均值。原生“不知道”等选项仍是原生选项，另保留其转入/转出，不能一概称为立场反转。

文本judge比较原题及前后两份完整观点，不看独立choice字段、A标签或模型身份。类别：未变=0；调整但主结论保留=0.5；主结论改变=1。无法判断单列。类别比例为主，编码均分为辅；不能把逐次分数相加当作首末变化，也不能把0.5称为“改变50%”。

### D：两种概率读数，不混成同一个指标

**D-choice**读取C无新增thinking的同次实际选项输出位置的完整候选概率，没有独立的reasoning开关。候选内归一化，read temperature=1。逐次与初始参照都使用：
`100 × [p_current(a_ref) − p_reference(a_ref)]`，其中a_ref是参照端实际选中的选项。保存全部选项概率，不只保存该差值。

**按09-26确认的新规则：**取同次生成返回的top-20中的原题候选字母概率，未返回的候选字母按0近似，再在候选集合内归一化；不再补评分。保存原始logprob、缺失字母清单和归一化前已返回候选的概率总量。补0是top-20截断近似，不声称缺失字母的真实概率就是0；若没有任何候选概率，归一化无定义，仍报错。已返回的非法数值、错误token位置及新增thinking仍不允许通过。read temperature保持1；不把“取得top-20”误称为采样时只允许top-20 token。

**D-text**固定接收当前peer消息前已保存的完整自身观点S，以及同一前置上下文H，建立两个隔离副本：

- H＋该事件真实peer消息；
- H＋近似等token长度的中性filler。

两个副本都问对逐字相同S的整体认同程度，均不新增thinking，直接读取七档概率；不先生成新回复，不纳入随后生成的正式回复（包括其A标签），不重新改写S。七档从完全反对到完全赞同编码1–7，中立为4。主指标为 `Σ k[p_argument(k)−p_control(k)]`。负值表示相对filler更不认同自己的原整段观点，不自动等于朝对手移动。

Filler执行建议沿用原稿实句：“The moderator noted the time and reminded participants that further remarks would follow in due course.” 按接收者tokenizer的长度比四舍五入重复，至少一次；只是近似匹配，保存实际长度。read temperature=1，不恢复top-two margin或entropy matching。D-text的A–G同样使用原top-20读数、缺项补0及候选内归一化；不调用额外补评分。

D-choice是纵向读数；D-text是同一事件的argument/control对照。两者都不是内在信念或持久改变的直接读出；D-text也不直接验证C全部文本语义变化。两次D-text读数是额外调用。

### E：同一个chairman，同一批初始回答

No-debate输入是三份实际正式初始回答；debate再加入所有正式分支消息，保留父子关系，共享节点仅一次。C/D读数不进入合成。每题每阵容一份no-debate合成跨tone复用：180份baseline＋540份debate synthesis。

单judge看匿名答案，交换顺序独立评两次，每次二选一。Debate得分为两次被选中的比例，取0/0.5/1；0.5表示两次选择不一致，不是质量等价。保留所有有效答案对，另报顺序不一致率。合成输入先用少量样本的词数检查，目标不靠近200K；不暗中截断或恢复逐请求tokenizer门槛。

## 5. 人工核查与统一汇总

已定两位独立标注者看同一批事件，每题1个；题库缩至60题后，按原规则对应60个事件，阵容大致均衡、不按tone配额。每人做60项B判断和60项C文本判断；C每事件选一对，兼顾逐次/首末，而不是两种都额外加。两人首轮互不见标签，也不见机器judge答案。用户先开始，第二位独立补齐；未补齐前不报告双人一致性。C选项与D不新增人工任务。

**统计执行建议，集中确认而非新实验：**

- 主报告按实际回复的A自报标签分组，展示B四档分布、C选项切换与文本类别、适用开放模型的D读数；tone合并，保留其元数据。阵容与接收模型清晰标明，不把D推广到未测闭源模型。
- 先给题目相同总权重，再用1/π校正B/C/D抽样；随后计算标签条件下的加权比例/均值。明确这是题目均衡总体中的条件汇总，不声称每个稀有标签都覆盖60题。
- T曲线按题内对应位置的目标节点数归一化。首末结果与逐次结果分开；共享终点只做一次测量，不把继承同一终点的多条分支当作独立证据。报告该终点对应的分支及汇总权重。
- 区间用题目级bootstrap：每次抽题时保留其全部阵容、tone、分支关系和测量记录；初始建议5,000次、95%区间。E同题配对。每格同时报有效题数、唯一事件数、缺测与无法判断。
- 以效应量、分布和区间为主，不给每个交叉小格机械增加显著性检验。无明确差异不等于等价；A标签是生成后观察量，不将其与C/D的关联解释为标签造成了变化。
- 人工核查报告两个人之间、judge与每个人之间的原始一致率及混淆表；若给AC1，明确类别和机会校正算法。保存原始独立标签，不以两人共识冒充无误真值。60事件不足以精确验证每个小子组。
