## Research motivation

旧研究的 A–C 和 D 使用不同模型、不同数据及不同实验流程，因此 D 不能解释 A–C 的机制。新的设计要把对同伴的认同、对原问题的自身立场、文本判断和选项概率连接到相同的主实验上。

核心问题包括：debate 改变了什么；什么因素控制这种变化；表达认同或反驳是否伴随自身立场变化；最终答案质量如何变化。

不要预先把以下说法当作已经确立的结论：tone 一定比模型组成更重要；debate 普遍没有质量收益；概率读数代表比文本更真实的内在信念。

## Confirmed: new layer definitions

### Layer A — 对同伴的自报认同，以及 tone 的作用

保留对每轮认同/反对标签的观察。用户确认将旧 C 的指令移除实验并入 A，形成两个互补角度：

1. **Tone comparison:** 从辩论开始使用不同的预设 tone，比较整个讨论过程中的认同/反对表现。
2. **Matched instruction ablation:** 固定已经发生的讨论内容，生成下一条回复时，一份保留 tone 指令，一份移除该指令。

用户明确同意：消融的两边都必须重新生成回复。不能只把移除指令后的新回复与原来的旧回复比较，否则会混入再次生成的波动。

这两个角度分别测整个 tone 条件的影响，以及固定讨论内容后当前指令的影响。若观察一致，可以形成更完整的证据，但不能事先保证显著性、效应大小或结论方向。

该消融不再叫独立的 Layer C，也不解释为持久信念测量。具体纳入哪些 tone、哪些轮次和上下文、如何抽样及是否重复生成，尚未确定。

### Layer B — 回复是否实质性地支持或反驳同伴

输入是同伴的发言与本成员的回复。外部 judge 判断回复文本是否支持或反驳同伴，不是判断成员自己对原问题的立场是否改变。

### New Layer C — 成员自己对原问题的立场是否改变

用户提出并确认保留两个测量分支：

1. **答案选项变化：**使用 GlobalOpinionQA 原题自带的选项，在辩论前及每轮后以固定问题、选项和询问措辞记录选择。额外测量不反馈进后续讨论。前后选项是否相同可直接由程序比较，不需要人工标注。
2. **观点文本变化：**外部 judge 比较同一个成员辩论前后对原问题表达的自身观点。即使所选答案没变，也可能在主张范围、适用条件或支持幅度上发生实质调整。

讨论中的示意例子（不是数据集中的真实样本）：都选“支持提高最低工资”，但主张从提高 20% 改成只提高 5%，选项相同而具体主张改变。

文本 judge 需要能指出相应文本证据。“你说得有道理”或措辞更温和本身不能证明自身立场变化。两种结果分别报告，不硬合成单一分数。

这是模型表达出的立场，不是对其内在信念的直接测量。每轮用于比较的具体观点文本如何获取、文本标签/rubric、比较相邻轮次还是统一对照初始回答等细节，尚未定。

### Layer D — 同一主实验中的选项概率测量

只在跨家族主阵容的两位开放权重成员上，进一步读取与 C 对应的原题答案选项概率，使概率研究成为同一批问题和讨论的延伸，而不是另外一组模型和另一批命题的独立研究。

具体读取时点、概率获得方式、对照、温度、指标和统计方法尚未确定。没有决定继续沿用旧研究的 A–G 量表、filler、T=2 或 entropy matching；也没有决定取消其中任意一项。

## Confirmed: model judging and human-audit scope

### LLM judges

- B 与新版 C 的文本分支采用三个独立的 LLM judges，使用各任务对应的评判标准。
- 在每项任务内部，三个 judges 评价同一批数据，分别报告结果及一致性。
- 不再指定一个主要 judge，仅让另外两个在很小的独立样本上验证它。
- 具体 judge 型号留待后面选。
- 跨 judge 一致不等于正确，仍可能存在共同错误。

### Human audit

已确认范围：人工核查只覆盖 B 的回复文本判断与 C 的观点文本变化判断。C 的直接选项比较不需要人工标注。

**提出但尚未单独明确确认的细节：**两位人类标注者独立评一部分样本；随机抽样覆盖不同 tone 和阵容；在不知道 LLM 标签的情况下先评；同时比较人与人、人与各 judge 的一致性。用户随后集中确认了 C 只核查文本分支，因此不要把人类标注者人数或完整抽样方案自动记为定案。

样本量、人员、标注流程和分歧处理均尚未确定。不要只选模型有分歧的样本来估计整体可靠性；若另做困难样本审查，应与代表性样本的结果区分。
